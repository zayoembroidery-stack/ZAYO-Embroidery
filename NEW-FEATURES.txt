🔍 4️⃣  ميزة الزوم والضغط على الصور
═══════════════════════════════════════════════════════════════════

💻 كيفية الاستخدام:
═════════════════════════════════════════════

   1. اذهب إلى قسم "المنتجات"
   2. اضغط على أي صورة منتج
   3. تظهر نافذة تكبير (Zoom Modal)
   4. شاهد الصورة بحجم أكبر
   5. اضغط على X أو خارج الصورة للإغلاق

🖥️  على الكمبيوتر:
   • الماوس: اضغط مرتين على الصورة
   • لوحة المفاتيح: اضغط Escape للإغلاق

📱 على الهاتف الذكي:
   • اللمس: اضغط مرة واحدة على الصورة
   • الإغلاق: اضغط على X أو أي مكان خارج الصورة

🎨 الميزات التقنية:
═════════════════════════════════════════════

   HTML العنصر:
   ──────────────────────────────────────────
   <div id="zoomModal" class="zoom-modal">
     <button class="zoom-close">&times;</button>
     <img id="zoomImage" src="">
   </div>

   CSS الأنماط:
   ──────────────────────────────────────────
   • خلفية سوداء شفافة (rgba)
   • صورة مركزية مع border radius
   • ظل 3D جميل
   • حركات سلسة (0.3s transition)

   JavaScript الدوال:
   ──────────────────────────────────────────
   • openZoom(imageSrc) - فتح نافذة التكبير
   • closeZoom() - إغلاق النافذة
   • click listener - للضغط على الصور

📦 كود الدوال:
═════════════════════════════════════════════

function openZoom(imageSrc) {
  document.getElementById('zoomImage').src = imageSrc;
  document.getElementById('zoomModal').classList.add('open');
}

function closeZoom() {
  document.getElementById('zoomModal').classList.remove('open');
}

// تفعيل الزوم على جميع الصور
document.querySelectorAll('.product-image').forEach(img => {
  img.addEventListener('click', function() {
    const imageSrc = this.querySelector('img').src;
    openZoom(imageSrc);
  });
});
